# Sash-s-Blinky-Badge
It's a 555 LED Chaser board (aka a Blinky!) and you can pin it to your clothes and show it off to your friends! It's also shaped like PACMAN!!!

## Components
- NE55p
- CD4017
- Electrolytic Capacitor
- Capacitor
- 1 ohm resistor
- 470 ohm resistor
- Potentiometer
- 10x LEDs
